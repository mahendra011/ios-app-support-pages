Support

Practical help for field use.

Start with manual coordinates

Enter latitude and longitude with east positive and west negative. On iPhone and iPad, “Use current site” requests foreground location only. Manual entry provides the complete workflow on both platforms.

If heading looks wrong

Move away from steel, magnets, vehicles, speakers, and energized equipment. Follow the system calibration prompt. When no reliable heading sensor is available, use manual heading and treat the values as coarse guidance.

If camera is unavailable

Diagram mode remains fully functional. Camera access is optional and requested only when you press Camera.

Deleting data

Use Delete in the active session. Saved sites, obstruction marks, notes, and generated handoff data are local to the app.
