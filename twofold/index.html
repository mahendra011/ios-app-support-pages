Two private choices. One shared plan.

Twofold is a private, one-device relationship check-in for two adults—not a quiz or chat. Both partners answer the same fixed questions about time, energy, pace, and connection modes. There are no user-written prompts, accounts, ads, or subscriptions.

Using Twofold

Start with the replayable four-card walkthrough. Partner A then answers privately, the screen conceals everything, and Partner B completes the same questions. Bring the device back together: Yes + Yes enters the Route, an allowed Maybe appears only under Talk first, and any mode with Not tonight stays hidden. The shorter time and gentler energy and pace shape the shared plan. Skip, Pause, and Stop remain available throughout.

Purchases

Lifetime access is one non-consumable, one-time in-app purchase that unlocks every premium mode and feature. There are no subscriptions, recurring fees, or ads. Use Restore Purchases on the lifetime screen when reinstalling with the same Apple Account.

Saved shared patterns

Lifetime users can optionally save mutual results, view them later, reuse only the shared time, energy and pace as undecided starting controls, or erase the pattern. Private answers are never stored.

Privacy and deletion

Private inputs are erased when a shared overlap is created. Use Erase everything to remove current state and any optional saved shared pattern.
