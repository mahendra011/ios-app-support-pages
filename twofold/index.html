Twofold Support

Twofold is a private, one-device couple connection compass. No account is required.

Using Twofold

Each adult takes a private turn, then brings the device back together. Only mutual choices appear. Maybe is discussion territory, not consent. Skip, Pause and Stop remain available throughout a route.

Purchases

Lifetime access is a one-time in-app purchase. Use Restore Purchases on the lifetime screen when reinstalling with the same Apple Account.

Privacy and deletion

Private inputs are erased when a shared overlap is created. Use Erase everything to remove current state and any optional saved shared pattern.
