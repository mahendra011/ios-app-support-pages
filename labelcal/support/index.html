Exact output starts with one good calibration.

LabelCal helps you measure printer drift, define physical label stock in millimetres, arrange a batch, inspect its proof, and print or export an exact-size PDF.

Reliable first print

  1. Confirm the page, grid, margins, gaps, and label dimensions shown under Stock.
  2. Print the calibration target at 100% or Actual Size. Disable Fit, Scale to Fit, and borderless enlargement.
  3. Measure the printed crosshair offset and scale, enter the results, then print a verification sheet.
  4. Record the residual. LabelCal marks the profile verified when it is within the displayed tolerance.
  5. Add text, a photo, image, or PDF; fill the desired cells; inspect Proof; then print or save the exact-size PDF.

Common fixes

  • Output is still shifted: confirm the print dialog is using 100% scale and the same paper size used during calibration.
  • Rows drift gradually: recheck X and Y scale, not only the offset.
  • Artwork looks soft: use a higher-resolution image or a vector PDF; review the resolution warning before output.
  • Printer settings changed: recalibrate after changing the printer, driver, tray, borderless mode, stock, or paper-size setting.
